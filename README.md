FastCar 🚗

O FastCar é um sistema de gerenciamento de locação de veículos desenvolvido como projeto acadêmico para a disciplina de Programação Orientada a Objetos.
Nosso objetivo é desenvolver uma aplicação desktop para auxiliar no gerenciamento de uma locadora de veículos, facilitando o controle de carros, clientes e aluguéis.

Tecnologias utilizadas:
- Java
- JavaFX
- MySQL
- Maven

Funcionalidades do sistema:
- Cadastro e gerenciamento de veículos
- Cadastro e gerenciamento de clientes
- Registro de locações
- Controle de devoluções

Status:
Em desenvolvimento.
